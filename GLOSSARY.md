# Glossary — the words this OS uses

A plain line each. No jargon left unexplained.

| Term | In one line |
|---|---|
| **rail** | A per-goal tracker — for each objective, it answers: on track, what's slipping, what's the next move. |
| **the cabinet** | A weekly meeting of AI "seats" reasoning from different angles — including one whose job is to argue you're wrong — that hands you a ranked set of moves. |
| **heartbeat** | The weekly routine that re-scores your goals and refreshes the top-line state — the system's pulse. |
| **routine** | A saved prompt the AI runs on a schedule (or on demand) — the heartbeat, the weekly review, etc. Each lives as one file in `_routines/`. |
| **canonical** | The one official home for a fact. If a number lives canonically in one file, every other file points to it rather than keeping its own copy. |
| **provenance** | Where a fact came from and when — stamped next to it, e.g. *(from the customer call, 12 May)* — so you can trust it later. |
| **fork** *(technical)* | Git's word for making your own copy of a project. Non-technical? Just copy the folder. |
| **cron** *(technical)* | The old unix word for a scheduled timer. You never need it — your AI app's "Scheduled Tasks" does the same thing with a day/time picker. |
| **wire up / register** | Telling your AI app to run a routine automatically — i.e. adding it as a scheduled task. |
